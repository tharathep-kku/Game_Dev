## Working on a game

1. Open Godot → **Import** → pick the `project.godot` inside its `source/...` folder.
2. **Project → Export → Web → Export Project**. Every preset already points at its web-build folder above, so exporting updates the live site after you push.

The `source/` folders were merged from their original repos with full commit history.
